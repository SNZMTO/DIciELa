# DICIELA — les décisions

> Une décision par numéro, datée, avec sa raison. Une décision qui en remplace une autre le dit ; l'ancienne est marquée
> « remplacée par la N ». Le GDD et l'architecture disent le présent ; ce fichier dit pourquoi.
